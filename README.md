# BackendMindset

Study notes for **back-end developer interviews**, written by me (Alireza Behmaneshrad) as a three-session course. Each session has a teaching handout split into **Mid-Level** and **Senior** parts, and the first session also has a Q&A sheet. The documents are in **Persian** (technical terms stay in English).

| Session | Topic | Files |
|---|---|---|
| 1 | Backend mindset and web fundamentals (API contracts, backward compatibility, HTTP basics, …) | `Session1/` — teaching handout (13 pages) + interview questions with model answers (7 pages) |
| 2 | Advanced C# (CLR, reference vs value types, collections, exceptions, resource management, …) | `Session2/` — teaching handout (19 pages) |
| 3 | ASP.NET | `Session3/` — teaching handout (8 pages) |

## How to use
Read the handout of a session, then answer the questions out loud before reading the model answers. The Mid-Level part defines every term used in the questions; the Senior part adds trade-offs and failure cases.
